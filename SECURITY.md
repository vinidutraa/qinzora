# Security policy

Qinzora is an open-source project, not a managed protection service. No supported-version SLA or complete protection guarantee is offered. Evaluate code and operational limits before deployment.

Never disclose credentials, private events or exploit instructions in public issues. If GitHub private vulnerability reporting is available, use **Security → Report a vulnerability**. Otherwise open an issue requesting a private reporting channel without vulnerability details or sensitive data. This policy does not assume that private reporting is enabled.

Ordinary bugs should include synthetic reproduction, version, environment and redacted output. See the documentation for application responsibilities and trust boundaries.
