# Contributing

Follow the repository [contribution guide](https://github.com/vinidutraa/qinzora/blob/main/CONTRIBUTING.md), [code of conduct](https://github.com/vinidutraa/qinzora/blob/main/CODE_OF_CONDUCT.md) and [security policy](https://github.com/vinidutraa/qinzora/blob/main/SECURITY.md).

Keep issues and pull requests focused and reproducible with synthetic examples. Preserve Python 3.12+ support, MIT licensing and security boundaries. Add regression coverage for behavior changes. Distinguish simulated providers from real inference and local checks from public deployments. Maintain English and the Portuguese README without discarding technical Portuguese guides.
