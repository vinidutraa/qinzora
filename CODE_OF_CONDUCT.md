# Code of conduct

Participate respectfully. Discuss code and evidence rather than attacking people. Harassment, discriminatory language, threats, unwanted contact and disclosure of private information are unacceptable.

Use constructive feedback, respect different experience levels and keep discussions relevant. Maintainers may remove harmful content or restrict participation. Use GitHub abuse-reporting mechanisms for private reports; never publish personal details in issues. No dedicated confidential reporting service or response SLA is promised.
